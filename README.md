# Fast Travel

## Azərbaycan dili

### Layihə haqqında

**Fast Travel** C# və Windows Forms istifadə edilərək hazırlanmış sadə səyahət və bilet rezervasiya proqramıdır.

Proqram istifadəçiyə şəhərlər arasında səyahət üçün bilet məlumatlarını daxil etməyə və biletləri siyahıda saxlamağa imkan verir.

### Əsas funksiyalar

- Gediş şəhərinin seçilməsi
- Təyinat şəhərinin seçilməsi
- Gediş və təyinat şəhərlərinin dəyişdirilməsi
- Səyahət tarixinin seçilməsi
- Səyahət saatının seçilməsi
- Ad və soyad məlumatlarının daxil edilməsi
- FIN kodunun yoxlanılması
- Telefon nömrəsinin daxil edilməsi
- Email ünvanının yoxlanılması
- Oturacaq nömrəsinin seçilməsi
- Biletin siyahıya əlavə edilməsi
- Biletin siyahıdan silinməsi
- Proqramdan çıxış

### İstifadə olunan texnologiyalar

- C#
- .NET
- Windows Forms
- Visual Studio
- Regular Expressions (Regex)

### Layihənin məqsədi

Layihənin əsas məqsədi C# Windows Forms mühitində istifadəçi interfeysi yaratmaq, istifadəçi məlumatlarını yoxlamaq və sadə bilet rezervasiya sisteminin iş prinsipini göstərməkdir.

## English

### About the Project

**Fast Travel** is a simple travel and ticket reservation application developed using C# and Windows Forms.

The application allows users to enter travel information, select cities, choose a date and time, enter passenger information, and manage tickets in a list.

### Main Features

- Select departure city
- Select destination city
- Swap departure and destination cities
- Select travel date
- Select travel time
- Enter passenger name and surname
- Validate FIN code
- Enter phone number
- Validate email address
- Select seat number
- Add tickets to the list
- Remove tickets from the list
- Exit the application

### Technologies Used

- C#
- .NET
- Windows Forms
- Visual Studio
- Regular Expressions (Regex)

### Project Purpose

The main purpose of this project is to demonstrate how to create a user interface with C# Windows Forms, validate user input, and implement the basic functionality of a simple ticket reservation system.
